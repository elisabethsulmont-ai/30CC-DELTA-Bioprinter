# Components bill

Everything needed to build one machine, on top of an Anycubic Kossel.
Printed parts are not listed here, they are in the 3D files folder.

Only three parts need to be sourced specifically. Everything else is standard and available
in any hardware store.

## Not bought

The stepper motor is the printer's original extruder motor.
The 26T and 60T pulleys are printed, see the 3D files folder.

## Starting point

The parts list of Emmanuel Hugnot's [300CC Extruder](https://www.thingiverse.com/thing:5215048)
is a good skeleton and it is already online. Start from it, and note for each line whether the
part was kept, changed or dropped.
