## Astuce de captation

Le guide de montage le plus rapide à produire est un **démontage photographié**. Tu démontes
la machine en photographiant chaque étape, tu inverses l'ordre, et le guide est écrit. Les
photos prises pendant un montage réel sont toujours meilleures que celles reconstituées.
